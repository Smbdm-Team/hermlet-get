# Hermlet: one-line setup

Hermlet (formerly SMBDM Agent) lets you use your own Hermes Agent from your phone, tablet or
another computer. Paste one line on the computer that runs Hermes:

- **Mac** (Terminal): `curl -fsSL https://smbdm-team.github.io/hermlet-get/install | bash`
- **Windows** (PowerShell): `irm https://smbdm-team.github.io/hermlet-get/install.ps1 | iex`

It also moves an SMBDM Agent (or earlier Hermlet) setup over (same link, same sign-in). After that, new versions install
themselves at night. Full steps: https://smbdm-team.github.io/hermlet-get

Set up with an older line (`smbdm-agent-get` in it)? That address is retired: paste the line above once and the
computer updates itself again from then on.
