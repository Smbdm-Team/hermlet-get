# Hermlo: one-line setup

Hermlo (formerly SMBDM Agent) lets you use your own Hermes Agent from your phone, tablet or another
computer. Paste one line on the computer that runs Hermes:

- **Mac** (Terminal): `curl -fsSL https://smbdm-team.github.io/smbdm-agent-get/install | bash`
- **Windows** (PowerShell): `irm https://smbdm-team.github.io/smbdm-agent-get/install.ps1 | iex`

It also moves an SMBDM Agent setup over (same link, same sign-in). After that, new versions install
themselves at night. Full steps: https://smbdm-team.github.io/smbdm-agent-get
