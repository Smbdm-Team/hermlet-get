SMBDM Agent is now Hermlo

Run this instead, once, on the computer where SMBDM Agent was set up. It moves your setup over: the same link and sign-in, so your phone keeps working. To get the new H icon, delete the old icon from the Home Screen and add the link again.

On a Mac

curl -fsSL https://smbdm-team.github.io/hermlo-get/install | bash

On Windows (PowerShell)

irm https://smbdm-team.github.io/hermlo-get/install.ps1 | iex
