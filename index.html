Set up Hermlet

Use your own Hermes Agent from your phone, with notifications. Version 0.10.2. Set it up on the computer where your Hermes Agent runs: a Mac or a Windows PC.

Before you start

  • Hermes Agent is installed on that computer.
  • Tailscale is on that computer and your phone, signed in with your work account, and says Connected.

On a Mac

Open the Terminal app, paste this line and press Return:

curl -fsSL https://smbdm-team.github.io/hermlet-get/install | bash

On Windows

Open PowerShell (Start menu, type PowerShell), paste this line and press Enter:

irm https://smbdm-team.github.io/hermlet-get/install.ps1 | iex

Then

Choose a username and a password (at least 8 characters) when it asks. At the end it shows your personal link: open it on your phone and add it to the Home Screen. Then turn on Push notifications in the app's Settings.

Coming from SMBDM Agent

SMBDM Agent is now Hermlet: paste the line above once. It moves your setup over: the same link and sign-in, your home-screen look and update settings, and keeps a copy of the old folder. Your phone keeps working; to see the new name, delete the old icon and add the link to the Home Screen again. If you use the native SMBDM Agent app, uninstall it first.

Update or repair

Paste the same line again. Your sign-in, link and chats stay the same.

Remove

Mac:

curl -fsSL https://smbdm-team.github.io/hermlet-get/install | bash -s -- --uninstall

Windows:

iex "& { $(irm https://smbdm-team.github.io/hermlet-get/install.ps1) } --uninstall"
